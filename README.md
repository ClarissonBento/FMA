# FMA
Trabalho Prático de Fundamentos da Teoria da Computação: Fábrica de poções baseadas no universo de The Witcher

Para executar o modo terminal no linux use:
    python3 main.py

Caso use windows use:
    python main.py

Para visualizar a interface pelo linux basta digitar o comando:
    python3 interface.py

Tambem pode ser usado o botão “Run Python File”.

É necessário o "Tkinter" e o "Pillow" para visualizar a interface, em algumas distribuições linux eles podem não vir instalados por padrão.

Para visualizar a interface pelo windows use:
    python interface.py
